# 小念 · Android UI 规格

> 基线：ChatGPT Android 当前版本（2026-11 截图 7 张）。
> 原则：**结构照搬，色彩收窄**——截图里的品牌色全部收成小念自己的一支紫，不复制任何 ChatGPT 标识与文案。

## 1. 设计 token

| 类别 | 值 | 用途 |
|---|---|---|
| `Ink` | `#0D0D0D` | 主文字（不用纯黑，避免发闷） |
| `InkSecondary` | `#8A8A8E` | 次要文字、未选中分段 |
| `InkTertiary` | `#B9B9BE` | 占位符、极弱提示 |
| `Canvas` | `#FFFFFF` | 页面底色 |
| `SurfaceMuted` | `#F4F4F5` | 输入条、圆形按钮底 |
| `SurfaceRaised` | `#EFEFF1` | 分段控件轨道 |
| `Divider` | `#E8E8EA` | 分隔线 |
| `Accent` | `#8B5CF6` | **唯一强调色**：主按钮、光标、语音 |
| `AccentDeep` | `#7C3AED` | 按下态 |

| 尺寸 | 值 |
|---|---|
| 圆形按钮 | 40dp（顶栏）、48dp（主操作）、44dp（输入条内） |
| 输入条圆角 | 26dp（胶囊形） |
| 顶栏高 | 56dp |
| 抽屉宽 | 320dp，右侧 26dp 圆角 |
| 会话行高 | ≈50dp（13dp 上下内边距） |
| 卡片/行圆角 | 10–12dp |

字体：系统无衬线，仅靠 weight 拉层次（标题 Bold 28sp，正文 16sp/24sp，标签 15sp Medium，微标 12sp）。

## 2. 已实现（首屏）

| 区域 | 规格 |
|---|---|
| 顶栏 | 左圆形「菜单」，中间居中胶囊「聊天 \| 工作」，右圆形「新对话」。分段用 Box 叠加保证**真正居中**，不用权重分配 |
| 会话列表 | 新会话页无内容区，最近会话**贴着输入框往上排**（`Spacer(weight)` 压底），24dp 圆角图标 + 单行省略标题 |
| 输入条 | 胶囊灰底 + 框内「＋」「麦克风」+ 框外 48dp 紫色圆按钮。**有文字时紫色按钮变发送箭头，无文字时是麦克风** |
| 抽屉 | 标题「小念」+ 搜索圆钮 → 定时任务/资料空间/自定义/设置 → 分隔线 → 会话历史 →「查看全部…」→ 底部紫色「新对话」+ 头像 |
