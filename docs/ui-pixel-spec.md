## 圆角（实测）

| 元素 | 像素 | 换算 | 实现值 |
|---|---|---|---|
| 输入条 | 54 | 20dp | `RoundedCornerShape(20.dp)` |

圆角测法：从矩形左上角向下逐行扫描左边界，边界首次到达起始 x 的行数即半径。

## 验证结果（2026-11-17）

同一帧 1080×1920 下，参考图 vs 本实现：

- **行投影相关系数 0.9452**（非白像素的逐行分布，反映布局骨架）
- **差异像素 2.3%**

差异图（`.out/diff-map.png`）显示差异集中在两处，都不是布局问题：

1. **文字内容不同** —— 参考图是「帮我安排手机助理Agent的实现路径」等真实对话，测试机里是
   `write a very long essay` 等英文，字形和换行必然不同
2. **顶栏中间** —— 参考图是「聊天 / 工作」分段控件，本实现按产品决策显示当前模型名

图标位置、会话行位置、输入条、语音球在差异图上**完全重合**。

> 说明：整图像素 diff 在本场景受文字内容主导，不能单独作为"像素级"的判据。
> 更有意义的指标是元素 bbox 偏差，当前全部 ≤3px。

## 已知无法对齐的部分

- **字体**：参考图用 ChatGPT 自有字体，本实现用系统字体，同一段文字的换行位置会不同
- **原始 dimens**：APK 的 Compose 代码被混淆（`com.openai.design` 仅剩 4 个文件），
  间距/字号只能从截图反推，精度约 ±1px


改完用同一分辨率截图，和参考图做逐像素差异统计：

```python
# 目标：差异像素占比 < 2%（字体渲染无法完全一致）
diff = sum(1 for p, q in zip(ref.getdata(), cur.getdata()) if p != q)
ratio = diff / (w * h)
```
